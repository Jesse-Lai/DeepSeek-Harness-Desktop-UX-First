# DSH Desktop

An open-source, polished native desktop experience built on [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness).

DSH Desktop is an independent community project focused on bringing DeepSeek Harness to macOS and Windows with thoughtful native integration, refined interaction design, and a cohesive desktop workflow.

## Direction

- Build on the DeepSeek Harness plugin ecosystem and runtime.
- Ship dedicated desktop applications for macOS and Windows.
- Preserve platform-native behavior: Liquid Glass on macOS and Fluent design on Windows.
- Provide a refined interface for sessions, workspaces, tools, approvals, and agent activity.
- Keep platform capabilities behind explicit, reusable Harness plugins.

## Status

Early planning and architecture work. The repository is not yet ready for general use.

## Relationship to DeepSeek Harness

DSH Desktop is not an official DeepSeek product. It is an independent desktop client built on the open-source DeepSeek Harness project.
