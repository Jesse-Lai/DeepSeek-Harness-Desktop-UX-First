# Security policy

## Supported versions

Security fixes are provided for the latest Stable release. Preview releases are supported only until the next
Preview or Stable release is available.

## Reporting a vulnerability

Use the repository's **Security** tab to submit a private vulnerability report. Do not publish exploit details,
credentials, API keys, or private conversation data in a public issue.

Release downloads are published only through GitHub Releases with SHA-256 checksums. Production downloads must
be signed and pass the platform verification steps in `docs/releasing-1.0.md`.
